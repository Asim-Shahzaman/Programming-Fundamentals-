## 🎯 Lab Objective
The objective of this lab is to learn how to use **loops in C++** to perform repetitive tasks efficiently, focusing on:
- `while` loop (entry-controlled)
- `do-while` loop (exit-controlled)

---

## 🧪 Lab Tasks

## 🔁 While Loop Tasks

### Task 1: Print Numbers from 1 to N
Write a C++ program that:
- Takes an integer **N** from the user
- Prints all numbers from **1 to N** using a `while` loop

---

### Task 2: Multiplication Table
Write a C++ program that:
- Takes a number from the user
- Displays its **multiplication table** using a `while` loop

---

### Task 3: Positive Number Validation
Write a C++ program that:
- Repeatedly asks the user to enter a **positive number**
- Displays an error message if the user enters **zero or a negative number**
- Keeps asking until a valid positive number is entered
- Displays the valid number and terminates

---

### Task 4: Sum of First Five Natural Numbers
Write a C++ program that:
- Uses a `while` loop
- Calculates the sum of the first **five natural numbers (1–5)**
- Displays the result

---

### Task 5: Menu-Driven Banking System
Write a C++ program that implements a simple banking system using a `while` loop:

**Features:**
- Default balance (e.g., 1000)
- Menu options:
  - Deposit money
  - Withdraw money (no negative balance allowed)
  - Check balance
  - Exit
- Program should:
  - Keep running until user chooses Exit
  - Handle invalid input and insufficient balance gracefully

---

## 🔂 Do-While Loop Tasks

### Task 6: Password Validation System
Write a C++ program that:
- Prompts the user to enter a password
- Keeps asking until the **correct password** is entered
- Uses a `do-while` loop

---

### Task 7: Restaurant Ordering System
Write a C++ program that:
- Displays a **menu and sub-menu** of food items
- Allows the user to:
  - Select items
  - Enter quantity (e.g., KG or units)
- Prices are fixed (as given)
- Calculates:
  - Total bill
- Allows ordering until the user decides to stop
- Uses a `do-while` loop
