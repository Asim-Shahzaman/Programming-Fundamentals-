## 🎯 Lab Objectives

## 🧪 Lab Tasks

## 🔹 Basic Tasks – Using `if` Only

### Task 1: Positive Number Check
Write a C++ program that:
- Takes an integer as input
- Checks if the number is **positive**
- Prints: *"The number is positive."*
- Uses **only `if` statement**

---

### Task 2: Even Number Check
Write a C++ program that:
- Takes an integer as input
- Checks if the number is **even**
- Prints: *"The number is even."*
- Uses **only `if` statement**

---

### Task 3: Largest of Three Numbers
Write a C++ program that:
- Takes **three integers** from the user
- Uses only `if` statements
- Displays the **largest number**

---

### Task 4: Student Grade System
Write a C++ program that:
- Takes student marks (out of 100)
- Determines grade using only `if` statements:

| Marks Range | Grade |
|------------|-------|
| ≥ 90 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| < 60 | Fail |

---

### Task 5: Traffic Signal System
Write a C++ program that:
- Takes traffic signal color as input:
  - `R` → Stop  
  - `G` → Go  
  - `Y` → Slow Down  
- Uses **only `if` statements**

## ⚙️ Challenge Task – Employee Payroll Management System
Write a C++ program that calculates **net salary** using only `if` statements.

### Salary Structure:
- Grade A → $50,000  
- Grade B → $30,000  
- Grade C → $20,000  

### Bonus Rules:
- ≥ 10 years → 10% bonus  
- 5–9 years → 5% bonus  
- < 5 years → No bonus  

### Tax Rules:
- Gross > $40,000 → 20% tax  
- $30,000–$40,000 → 10% tax  
- < $30,000 → No tax  

### Formula:
**Net Salary = Gross Salary − Tax**

## 🔸 Basic Tasks – Using `if-else`

### Task 6: ATM Simulation
Write a C++ program that:
- Takes account balance
- Takes withdrawal amount
- If withdrawal ≤ balance:
  - Deduct and show remaining balance
- Else:
  - Display *"Insufficient balance"*

---

### Task 7: Loan Eligibility Checker
Write a C++ program that:
- Checks loan eligibility using `if-else`
- Conditions:
  - Minimum salary ≥ $25,000
  - OR salary ≥ $20,000 with experience > 5 years
- Displays eligibility result
