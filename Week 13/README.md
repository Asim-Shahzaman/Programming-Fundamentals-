## 🎯 Lab Objectives
This lab focuses on strengthening the understanding of pointers in C++. By completing these tasks, we will learn:

- How pointers store memory addresses  
- How to use dereferencing operators  
- How to modify values using pointers  
- How pointers work with arrays and functions  
- How to use `nullptr` and `void` pointers safely  

---

## 🧪 Lab Tasks

### Task 1: Basic Pointer and Dereferencing
Write a C++ program to:
- Declare an integer variable and initialize it with a value  
- Declare a pointer to store the address of the integer  
- Use the dereferencing operator (`*`) to display the value of the variable  

---

### Task 2: Modify Variable Using Pointer
Write a C++ program to:
- Declare an integer variable and a pointer pointing to it  
- Change the value of the variable using the pointer  
- Display the modified value  

---

### Task 3: Array Access Using Pointer Arithmetic
Write a C++ program to:
- Declare an array of integers  
- Use a pointer to access and display each array element  
- Apply pointer arithmetic to traverse the array  

---

### Task 4: Swapping Values Using Pointers
Write a C++ program to:
- Create a function that swaps two numbers  
- Pass arguments to the function using pointers  
- Display the values before and after swapping  

---

### Task 5: Null Pointer Check
Write a C++ program to:
- Declare a pointer and initialize it to `nullptr`  
- Check whether the pointer is null  
- Display a message indicating that it does not point to valid memory  
- If not null, display the memory address stored in the pointer  

---

### Task 6: Void Pointer Usage
Write a C++ program to:
- Declare a `void` pointer  
- Assign it the address of an integer variable  
- Cast the void pointer to the appropriate type  
- Use it to access and display the integer value
