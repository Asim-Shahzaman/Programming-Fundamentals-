## 🎯 Lab Objectives
The objective of this lab is to understand the concept of **arrays in C++**, including:
- Initializing arrays  
- Traversing arrays using loops  
- Finding specific elements  
- Performing calculations  
- Understanding array properties such as size and indexing  

---

## 🧪 Lab Tasks

### Task 1: Initialize and Print an Array
Write a C++ program that:
- Initializes an array of **five integers**
- Traverses the array using a loop
- Prints all array elements

---

### Task 2: Print an Array in Reverse Order
Write a C++ program that:
- Takes input of an array of **N integers** from the user
- Prints the array elements in **reverse order**

---

### Task 3: Calculate Sum and Average of Array Elements
Write a C++ program that:
- Initializes an array of integers
- Calculates the **sum** of array elements
- Calculates and displays the **average**

---

### Task 4: Find the Length of an Array
Write a C++ program that:
- Initializes an array of integers
- Calculates and prints the **size (length)** of the array using the `sizeof()` operator

---

### Task 5: Find the Largest Number in an Array
Write a C++ program that:
- Prompts the user to input an array of **N integers**
- Determines and displays the **largest number** in the array
