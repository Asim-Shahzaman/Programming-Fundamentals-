## 🎯 Lab Objectives
The objective of this lab is to introduce us to the **fundamentals of programming** and basic **C++ concepts**.  
This includes practicing:
- Setting up the C++ development environment  
- Writing simple C++ programs  
- Using `cout` for console output  
- Applying escape sequences for formatted output  

---

## 🧪 Lab Tasks

## Task 1: Welcome Message
- Display a **three-line welcome message**
- Use separate `cout` statements
- Print each line on a new line using `endl`

---

## Task 2: Printing a Pattern
- Write a program that prints a **given pattern** on the console using `cout`

---

## Task 3: Tabular Output
- Display text in a **tabular format**
- Use escape sequences `\t` and `\n`
- Print column headings on one line and sample data on the next

---

## Task 4: Message Using Escape Sequences
- Display a message that includes:
  - Quotation marks
  - A file path using backslashes
  - A new line character
