---

## 🧪 Lab Tasks

## 🔹 Task 1: Even or Odd Using Ternary Operator
Write a C++ program that:
- Takes an integer input from the user
- Uses the **ternary operator** to determine if the number is **even or odd**
- Output format:
  - *"The number X is even"*  
  - *"The number X is odd"*

---

## 🔹 Task 2: Age Group Classification
Write a C++ program that:
- Takes age as input
- Uses the **ternary operator** to classify age:
  - Age < 13 → Child  
  - Age 13–19 → Teenager  
  - Age ≥ 20 → Adult  
- Displays the age category in the given format

---

## 🔹 Task 3: Banking App Using Ternary & Logical Operators
Write a C++ program that:
- Takes account balance as input
- Determines **account type** using the ternary operator:
  - Balance < $100 → Low Balance Account  
  - $100–$500 → Standard Account  
  - > $500 → Premium Account  
- Takes loyalty status (1 = loyal, 0 = not loyal)
- Determines **special offer eligibility**:
  - Balance > $200 **AND** loyal customer
- Uses **only ternary and logical operators**
- Does **not** use `if-else`
