## 🎯 Objectives
The objectives of this lab are to:
- Learn how to declare and initialize variables
- Understand different **data types** and their usage
- Identify valid and invalid **identifiers**
- Understand the use of **constants**
- Learn proper use of **comments** in C++ programs

---

## 🧪 Tasks

### Task 1: Squared Distance Calculation
Write a C++ program to:
- Initialize coordinates of two points
- Calculate squared distance using:
```
(x2 - x1)² + (y2 - y1)²
```

---

### Task 2: Total Purchase Calculation
Write a C++ program that:
- Stores prices of five items
- Calculates:
  - Subtotal
  - Sales tax (6%)
  - Total amount
- Uses constants where appropriate

---

### Task 3: Average of Test Scores
Write a C++ program that:
- Initializes three test scores
- Calculates the average
- Displays the result rounded to **two decimal places**
