## 🎯 Lab Objectives
The objective of this lab is to understand the concept of **arrays in C++**.  
This includes practicing:
- Initializing arrays  
- Traversing arrays using loops  
- Performing calculations on array elements  
- Finding specific values  
- Understanding array size and indexing  

---

## 🧪 Lab Tasks

### Task 1: Initialize and Print an Array
Write a C++ program to:
- Initialize an array of **five integers**
- Traverse the array using a loop
- Print all array elements

---

### Task 2: Print an Array in Reverse Order
Write a C++ program to:
- Ask the user to input an array of **N integers**
- Print the array elements in **reverse order**

---

### Task 3: Calculate Sum and Average of Array Elements
Write a C++ program to:
- Initialize an array of integers
- Calculate the **sum** of all elements
- Calculate and display the **average** of the elements

---

### Task 4: Find the Length of an Array
Write a C++ program to:
- Initialize an array of integers
- Calculate and print the **size (length)** of the array using the `sizeof()` operator

---

### Task 5: Find the Largest Number in an Array
Write a C++ program to:
- Prompt the user to input an array of **N integers**
- Determine and display the **largest number** in the array
