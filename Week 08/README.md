## 🎯 Lab Objective
The objective of this lab is to learn how to use the **switch statement in C++** to control the flow of a program based on specific user inputs.

---

## 🧪 Lab Tasks

### Task 1: Simple Calculator
Write a C++ program that:
- Takes **two numbers** from the user
- Takes an **operator** (`+`, `-`, `*`, `/`)
- Uses a `switch` statement to perform the selected operation
- Displays an error message for an invalid operator

---

### Task 2: Day of the Week
Write a C++ program that:
- Takes an integer input **(1–7)**
- Uses a `switch` statement to display the corresponding day of the week  
  (e.g., 1 → Monday, 2 → Tuesday, etc.)
- Displays an error message if the number is not between 1 and 7

---

### Task 3: Area Calculator for Different Shapes
Write a C++ program that:
- Uses a `switch` statement to let the user select a shape:
  - 1 → Circle  
  - 2 → Rectangle  
  - 3 → Triangle  
- Takes required dimensions from the user
- Calculates and displays the area of the selected shape

---

### Task 4: Currency Converter
Write a C++ program that:
- Uses a `switch` statement to select currency conversion:
  - USD to PKR  
  - USD to INR  
  - USD to Euros  
- Takes the amount in USD as input
- Displays the converted amount using predefined exchange rates

---

### Task 5: Shopping System with Invoice and Discounts
Write a C++ program that:
- Allows the user to select a **category** using `switch`:
  - Electronics  
  - Clothing  
  - Groceries  
- Allows selection of items within the chosen category
- Takes **quantity** as input
- Calculates total price
- Applies discount based on total amount:
  - Below $100 → No discount  
  - $100 – $500 → 10% discount  
  - Above $500 → 20% discount  
- Generates and displays a **final invoice**

#### Items & Prices:
- **Electronics:** Laptop ($1000), Smartphone ($700), Headphones ($150)  
- **Clothing:** Jacket ($120), T‑shirt ($40), Jeans ($60)  
- **Groceries:** Milk ($2/L), Bread ($3), Eggs ($5/dozen)
