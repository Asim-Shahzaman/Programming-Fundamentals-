## 🎯 Lab Objective
The objective of this lab is to understand and practice the concept of **functions in C++**, including library functions, user-defined functions, and menu-driven programs.

---

## 🧪 Lab Tasks

### Task 1: Library Functions
Write a C++ program that uses **library functions** to calculate the following for a number input by the user:
- Square Root  
- Absolute value  
- Sine  
- Cosine  
- Power of 3  

---

### Task 2: User Defined Function – Greeting Message
Write a C++ program that:
- Defines a function with **void return type**
- Takes no parameters
- Displays the message:  
  **"Hello, Welcome to C++ Functions!"**
- Calls the function from `main()`

---

### Task 3: User Defined Function – Even or Odd
Write a C++ program that:
- Defines a function to check whether a number is **even or odd**
- Takes an integer as a parameter
- Uses an **if-else statement**
- Prints:
  - "Even" if divisible by 2  
  - "Odd" otherwise
- Call the function with different values from `main()`

---

### Task 4: User Defined Function – Factorial Calculation
Write a C++ program that:
- Defines a function to calculate the **factorial** of a number
- Uses a **loop**
- Returns the factorial value
- Prompts the user for input in `main()` and displays the result

---

### Task 5: Menu-Driven Calculator Program
Write a C++ program that:
- Displays a menu with operations:
  - Addition  
  - Subtraction  
  - Multiplication  
  - Division  
- Allows the user to select an operation
- Takes two numbers as input
- Uses **separate functions** for each operation
- Displays the result
- Allows multiple calculations until the user chooses to exit

---

### Task 6: Menu-Driven Restaurant Bill Program
Write a C++ program that:
- Displays a menu with **at least five food items** and prices
- Allows the user to:
  - Select items
  - Enter quantity
- Uses a function to calculate item cost  
  `(total = price × quantity)`
- Allows ordering multiple items
- Uses another function to calculate:
  - Final bill
  - Tax or service charge (e.g., 10%)
- Displays the final total before exit

#### Suggested Functions:
- Function to display menu  
- Function to calculate item cost  
- Function to calculate final bill with tax
